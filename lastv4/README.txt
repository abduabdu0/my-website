README — состояние текущего репозитория
=====================================

Кратко — сделанные изменения и текущее состояние:

- Цветовая палитра и верстка обновлены для светлой темы.
- Все фронтенд-скрипты перенесены внутрь соответствующих HTML-файлов (JS встроен в `index.html` и `services.html`).
- Ресурсы (изображения) перемещены в папку `img/`.
- Серверная часть была удалена из этой копии репозитория — в текущем архиве нет Flask-сервера.

Что сейчас важно знать
- Формы на страницах не отправляют POST на локальный сервер — они используют переходы в WhatsApp/Telegram или встроенную логику в HTML.
- Если вам нужен backend (сохранение в Excel, отправка email), восстановите папку `server/` и настройте `server/app.py` и `requirements.txt`.

Файлы, которые можно изменить для кастомизации
- Поменяйте изображения в `img/` (например, `img/iphone17promax.jpg`).
- Если хотите добавить видео-фон, положите `neutral.mp4` в `img/video/neutral.mp4` и обновите HTML вручную.

Как тестировать локально
1. Откройте `index.html` и `services.html` в браузере (двойной клик или через локальный HTTP сервер).
2. Проверяйте консоль браузера для ошибок (DevTools → Console).

Если нужно восстановить сервер
- Я могу восстановить или повторно добавить пример сервера (Flask) по запросу и обновить инструкции.

Если хотите — могу автоматически проверить все страницы в headless-режиме и собрать список оставшихся ошибок.
